📥 实验十 插入排序

通过动画模拟理解直接插入排序的执行过程

📖 算法原理

直接插入排序（Insertion Sort）把数组分成「已排序区」和「未排序区」两部分，初始时已排序区只包含第一个元素。每一趟取出未排序区的第一个元素暂存到 temp，然后在已排序区中从后往前依次与 temp 比较：若该元素大于 temp，则把它向后移动一位；直到找到不大于 temp 的元素或到达数组头部，再把 temp 插入到空出的位置。重复该过程，直到未排序区为空。

时间复杂度：最好 O(n)，最坏/平均 O(n²)　空间复杂度：O(1)　稳定性：稳定

💻 算法代码

void InsertSort(int arr[], int n) {


  for (int i = 1; i < n; i++) {        // 依次把 arr[i] 插入前面的有序区


    int temp = arr[i];               // 暂存待插入元素


    int j = i - 1;


    while (j >= 0 && arr[j] > temp) { // 从后往前比较


      arr[j + 1] = arr[j];             // 大于 temp 则后移一位


      j--;


    }


    arr[j + 1] = temp;               // 插入到正确位置


  }


}

📝 实验要点

  • 已排序区从 1 个元素开始，每趟扩大一个元素，最多进行 n-1 趟
  • 待插入元素必须先暂存到 temp，否则后移操作会覆盖它的值
  • 比较和移动都从已排序区末尾向前进行，遇到不大于 temp 的元素即停止
  • 插入排序是稳定排序：相等元素不会越过彼此，相对顺序不变
  • 数据基本有序时移动和比较次数很少，最好情况时间复杂度为 O(n)
