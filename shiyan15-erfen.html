🎯 实验十五 二分法排序（折半插入排序）

用二分查找确定插入位置，再进行元素后移与插入

📖 算法原理

折半插入排序（二分法排序）是直接插入排序的改进版本。它把序列看作「已排序前缀 + 待插入元素」两部分：第 i 趟将 arr[i] 暂存到 temp，然后在已排序前缀 [0, i-1] 中用折半查找确定插入位置（初始 low=0、high=i-1，每次取 mid=(low+high)/2 与 temp 比较），找到位置后再把该位置之后的元素逐个后移，最后把 temp 插入。

由于查找阶段使用二分，比较次数由直接插入排序的 O(i) 降为 O(log i)，但移动次数仍为 O(i)，因此整体时间复杂度仍为 O(n²)。

时间复杂度：O(n²)　空间复杂度：O(1)　稳定性：稳定（arr[mid] > temp 时才向左收缩，相等元素保持原有次序）

💻 算法代码

void BinInsertSort(int arr[], int n) {


  for (int i = 1; i < n; i++) {          // i 为待插入元素下标


    int temp = arr[i];                   // 暂存待插入元素


    int low = 0, high = i - 1;           // 折半查找区间 [low, high]


    while (low <= high) {                // 区间非空则继续折半


      int mid = (low + high) / 2;       // mid：区间中点


      if (arr[mid] > temp) high = mid - 1; // temp 应在左半区


      else low = mid + 1;                 // temp 应在右半区（相等时靠后 → 稳定）


    }


    for (int j = i - 1; j >= low; j--)     // 从后往前逐个后移，腾出位置


      arr[j + 1] = arr[j];


    arr[low] = temp;                     // low 即最终插入位置


  }


}

📝 实验要点

  • 折半插入排序只在查找插入位置时使用二分，元素移动仍需逐个进行，所以总体仍是 O(n²)
  • 循环结束时 low 就是插入位置，此时 low > high，且前缀中 [0, low-1] 均 ≤ temp
  • 比较条件写 arr[mid] > temp 才能保证稳定性；写成 >= 会让相等元素逆序
  • 折半查找只适用于顺序存储的有序表，链式结构无法随机访问 mid
  • 当 n 较小时，直接插入排序反而更快（折半查找的额外判断有开销）
