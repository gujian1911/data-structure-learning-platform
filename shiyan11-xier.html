🧩 实验十一 希尔排序

通过动画模拟理解希尔排序的分组插入过程

📖 算法原理

希尔排序（Shell Sort）又称缩小增量排序，是直接插入排序的改进版本。它先选取一个增量 gap，把待排序序列按下标间隔 gap 分成若干组，对每组分别做直接插入排序；然后不断缩小增量，重复上述分组与组内插入排序的过程。随着增量逐渐减小，序列的"局部有序"程度越来越高，当增量减为 1 时，整个序列再做一次直接插入排序即可完成，此时序列已基本有序，插入排序的效率最高。

常用的增量序列为 n/2、n/4、n/8……直到 1（每次折半）。时间复杂度：平均约 O(n^1.3)，最坏 O(n²)　空间复杂度：O(1)　稳定性：不稳定

💻 算法代码

void ShellSort(int arr[], int n) {


  for (int gap = n / 2; gap > 0; gap /= 2) {    // 增量逐步缩小，直到 1


    for (int g = 0; g < gap; g++) {            // 按 gap 划分出 gap 个分组


      for (int i = g + gap; i < n; i += gap) { // 组内做直接插入排序


        int temp = arr[i];                    // 待插入元素


        int j = i - gap;


        while (j >= 0 && arr[j] > temp) {      // 比 temp 大的元素后移 gap 位


          arr[j + gap] = arr[j];


          j -= gap;


        }


        arr[j + gap] = temp;                  // 插入到正确位置


      }


    }


  }


}

📝 实验要点

  • 希尔排序是缩小增量排序：增量取 n/2、n/4……依次折半，直到 1
  • 每个增量 gap 下，序列被分成 gap 个组，下标相差 gap 的元素属于同一组
  • 组内采用直接插入排序，只是元素移动的步长由 1 变成了 gap
  • 增量较大的阶段让元素大步跳跃移动，使序列快速趋于"基本有序"
  • 当 gap = 1 时退化为普通的直接插入排序，此时序列已接近有序，效率很高
  • 希尔排序是不稳定排序，且增量序列的选取会显著影响算法性能
