🔍 实验七 二分法查找

通过动画模拟理解二分查找（折半查找）的执行过程

📖 算法原理

二分查找（Binary Search）是一种在有序数组中查找某一特定元素的搜索算法。搜索过程从数组的中间元素开始，如果中间元素正好是要查找的元素，则搜索过程结束；如果某一特定元素大于或者小于中间元素，则在数组大于或小于中间元素的那一半中查找，而且跟开始一样从中间元素开始比较。如果在某一步骤数组为空，则代表找不到。

前提条件：数组必须有序（升序或降序）

时间复杂度：O(log₂n)　空间复杂度：O(1)

💻 算法代码

int BinarySearch(int arr[], int n, int key) {


  int low = 0, high = n - 1, mid;


  while (low <= high) {


    mid = (low + high) / 2;        // 计算中间位置


    if (arr[mid] == key)


      return mid;              // 找到，返回下标


    else if (arr[mid] < key)


      low = mid + 1;           // 在右半部分查找


    else


      high = mid - 1;          // 在左半部分查找


  }


  return -1;                  // 未找到


}

📝 实验要点

  • 二分查找要求数组必须有序，无序数组需先排序
  • 每次比较后，查找范围缩小一半，效率远高于顺序查找
  • 注意 mid = (low + high) / 2 的计算，以及 low <= high 的循环条件
  • 当 low > high 时查找失败，说明元素不在数组中
  • 二分查找适用于顺序存储的有序表，不适用于链表
