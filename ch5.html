二叉树的遍历

二叉树的递归遍历

📝 本章核心知识点

一、树的基本概念

  • 定义：n（n≥0）个结点的有限集合，n=0时为空树
  • 术语：根、叶子、度、孩子、双亲、兄弟、层次、深度、高度
  • 性质：树中结点数 = 所有结点度数之和 + 1
  • m叉树：每个结点最多有m个孩子

二、二叉树

  • 定义：每个结点最多有两棵子树（左子树和右子树），子树有左右之分
  • 性质1：第i层最多有2^(i-1)个结点（i≥1）
  • 性质2：深度为k的二叉树最多有2^k - 1个结点
  • 性质3：n₀ = n₂ + 1（叶子结点数 = 度为2的结点数 + 1）
  • 满二叉树：深度为k且有2^k - 1个结点
  • 完全二叉树：除最后一层外每层都满，最后一层结点集中在左侧
  • 完全二叉树深度：⌈log₂(n+1)⌉ 或 ⌊log₂n⌋+1

三、二叉树的遍历

  • 先序遍历：根 → 左子树 → 右子树
  • 中序遍历：左子树 → 根 → 右子树
  • 后序遍历：左子树 → 右子树 → 根
  • 层次遍历：从上到下、从左到右，用队列实现
  • 重要结论：已知先序+中序或后序+中序可唯一确定二叉树

四、线索二叉树

  • 线索化：利用空指针域存放前驱和后继指针
  • 标志位：ltag/rtag为0表示指向孩子，为1表示线索

五、哈夫曼树

  • 定义：带权路径长度WPL最小的二叉树
  • 构造：每次选两个权值最小的结点合并，新结点权值为两者之和
  • 哈夫曼编码：左0右1，前缀编码，使总编码长度最短

六、二叉排序树与平衡二叉树

  • 二叉排序树：左子树 < 根 < 右子树，中序遍历得到有序序列
  • 查找效率：最好O(log₂n)，最坏O(n)（退化为单支树）
  • 平衡二叉树（AVL）：左右子树高度差绝对值≤1
  • 平衡调整：LL、RR、LR、RL四种旋转
