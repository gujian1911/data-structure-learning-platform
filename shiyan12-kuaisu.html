⚡ 实验十二 快速排序

通过动画模拟理解快速排序的划分与递归过程

📖 算法原理

快速排序（Quick Sort）是一种基于分治法的高效排序算法。它的基本思想是：在待排序区间中选取一个元素作为基准（pivot），通过一趟划分（Partition）把区间内的元素分成两部分，使得基准左侧的元素都不大于基准、右侧的元素都不小于基准；此时基准已落在它的最终位置上。然后再对左右两个子区间递归执行同样的划分过程，直到子区间长度不超过 1，整个序列即告有序。

本实验采用 Lomuto 划分方案：取区间最后一个元素为基准，用指针 i 记录「小于等于基准」区域的末尾，指针 j 从左向右扫描，遇到不大于基准的元素就把它扩展到左区间，扫描结束后把基准交换到 i+1 处。

时间复杂度：平均 O(nlog₂n)，最坏 O(n²)（每次划分极不均衡时）　空间复杂度：O(log n)（递归栈）　稳定性：不稳定

💻 算法代码

void QuickSort(int arr[], int lo, int hi) {


  if (lo >= hi) return;              // 区间长度 ≤ 1，无需排序


  int p = Partition(arr, lo, hi);     // 划分，返回基准的最终位置


  QuickSort(arr, lo, p - 1);          // 递归排序左子区间


  QuickSort(arr, p + 1, hi);          // 递归排序右子区间


}


 


int Partition(int arr[], int lo, int hi) {


  int pivot = arr[hi];                // 取最后一个元素为基准


  int i = lo - 1;                     // i 指向「≤ 基准」区域的末尾


  for (int j = lo; j < hi; j++) {


    if (arr[j] <= pivot) {            // 不大于基准，纳入左区间


      i++;


      int temp = arr[i]; arr[i] = arr[j]; arr[j] = temp;


    }


  }


  int temp = arr[i + 1];              // 基准交换到分界处


  arr[i + 1] = arr[hi];


  arr[hi] = temp;


  return i + 1;                      // 基准就位，返回其索引


}

📝 实验要点

  • 快速排序是分治法的典型应用：划分 + 递归处理左右子区间
  • 每趟划分后基准元素落到最终位置，此后不再参与比较
  • 划分的均衡程度决定效率：均匀划分时递归深度约 log₂n，比较次数约 nlog₂n
  • 最坏情况（如已有序且固定取端点为基准）退化为 O(n²)，可用「三数取中」或随机基准优化
  • 快速排序是不稳定排序：交换过程可能打乱相等元素的相对顺序
  • 递归栈深度平均为 O(log n)，最坏为 O(n)
