📝 本章核心知识点

一、栈（Stack）

  • 定义：只允许在一端（栈顶）进行插入和删除操作的线性表
  • 特点：后进先出（LIFO, Last In First Out）
  • 顺序栈：用数组实现，栈空条件top=-1，栈满条件top=MAXSIZE-1
  • 链栈：用链表实现，入栈和出栈都在表头进行
  • 时间复杂度：入栈和出栈都是O(1)

二、队列（Queue）

  • 定义：只允许在一端（队尾）插入、另一端（队头）删除的线性表
  • 特点：先进先出（FIFO, First In First Out）
  • 顺序队列：用数组实现，存在"假溢出"问题
  • 循环队列：解决假溢出，队空：(rear+1)%MAXSIZE==front；队满：(rear+1)%MAXSIZE==front（需牺牲一个单元区分）
  • 元素个数：(rear - front + MAXSIZE) % MAXSIZE
  • 链队列：用链表实现，队头指针指向头结点，队尾指针指向尾结点

三、应用场景

  • 栈：表达式求值、括号匹配、函数递归调用、深度优先搜索、浏览器后退
  • 队列：层次遍历（BFS）、缓冲区、打印机任务调度、CPU进程调度
