📋 实验九 选择排序

通过动画模拟理解选择排序的执行过程

📖 算法原理

选择排序（Selection Sort）是一种简单直观的排序算法。它的工作原理是：首先在未排序序列中找到最小（大）元素，存放到排序序列的起始位置，然后，再从剩余未排序元素中继续寻找最小（大）元素，然后放到已排序序列的末尾。以此类推，直到所有元素均排序完毕。

时间复杂度：最好/最坏/平均均为 O(n²)　空间复杂度：O(1)　稳定性：不稳定

💻 算法代码

void SelectionSort(int arr[], int n) {


  for (int i = 0; i < n - 1; i++) {


    int minIdx = i;               // 假设当前位置为最小值


    for (int j = i + 1; j < n; j++) {


      if (arr[j] < arr[minIdx])    // 找到更小的值


        minIdx = j;              // 更新最小值下标


    }


    if (minIdx != i) {             // 交换到正确位置


      int temp = arr[i];


      arr[i] = arr[minIdx];


      arr[minIdx] = temp;


    }


  }


}

📝 实验要点

  • 每趟排序在未排序部分找到最小值，与当前位置交换
  • 选择排序的比较次数固定为 n(n-1)/2，与初始顺序无关
  • 交换次数最多 n-1 次，远少于冒泡排序
  • 选择排序是不稳定排序：相等元素可能因交换改变相对顺序
  • 与冒泡排序的区别：冒泡每趟多次交换，选择每趟最多交换一次
