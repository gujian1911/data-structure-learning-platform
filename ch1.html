📝 本章核心知识点

一、数据结构三要素

  • 逻辑结构：数据元素之间的逻辑关系，包括集合、线性结构、树形结构、图形结构
  • 存储结构（物理结构）：数据在计算机内存中的表示，包括顺序存储、链式存储、索引存储、散列存储
  • 运算：对数据进行的操作，如增删改查、排序、遍历等

二、基本概念

  • 数据：信息的载体，是描述客观事物的符号集合
  • 数据元素：数据的基本单位，由若干数据项组成
  • 数据项：构成数据元素的不可分割的最小单位
  • 数据对象：性质相同的数据元素的集合

三、算法与复杂度

  • 算法特性：有穷性、确定性、可行性、输入（0个或多个）、输出（1个或多个）
  • 时间复杂度：T(n) = O(f(n))，常见级别：O(1) < O(log₂n) < O(n) < O(nlog₂n) < O(n²) < O(n³) < O(2ⁿ)
  • 空间复杂度：S(n) = O(f(n))，算法执行所需的辅助存储空间
  • 大O记号：表示算法时间复杂度的上界
