🏔️ 实验十三 堆排序

通过动画模拟理解建堆与反复筛选的过程

📖 算法原理

堆排序（Heap Sort）利用大根堆的性质进行排序：大根堆是一棵完全二叉树，且任一结点的值都大于或等于其左右孩子的值，因此堆顶元素就是整个堆中的最大值。

排序过程分两步：第一步建堆，把待排序序列看成一棵完全二叉树，从最后一个非叶结点（索引 n/2-1）开始自底向上逐个下沉调整，使整棵树满足大根堆性质；第二步反复筛选，每次把堆顶元素与当前堆的末尾元素交换，堆长度减一，再对新的堆顶执行一次下沉调整，使剩余部分重新成为大根堆。如此重复，末尾的已排序区间从右向左不断扩大，直到堆中只剩一个元素。

由于下标从 0 开始时，结点 i 的左孩子为 2i+1、右孩子为 2i+2，下沉调整沿父子路径进行，树高为 ⌊log₂n⌋+1，因此每次筛选至多比较、移动 O(log₂n) 次。

时间复杂度：建堆 O(n)，每次筛选 O(log₂n)，共 n-1 次，总体 O(nlog₂n)（最好、最坏、平均均如此）　空间复杂度：O(1)　稳定性：不稳定

💻 算法代码

/* 下沉调整：将以 k 为根的子树调整为大根堆，len 为当前堆长度 */


void SiftDown(int arr[], int k, int len) {


  while (1) {


    int l = 2 * k + 1;          // 左孩子


    int r = 2 * k + 2;          // 右孩子


    int max = k;


    if (l < len && arr[l] > arr[max]) max = l;  // 取较大孩子


    if (r < len && arr[r] > arr[max]) max = r;


    if (max == k) break;          // 已满足大根堆性质


    int t = arr[k]; arr[k] = arr[max]; arr[max] = t;  // 与较大孩子交换


    k = max;                          // 继续向下调整


  }


}


 


void HeapSort(int arr[], int n) {


  for (int i = n / 2 - 1; i >= 0; i--)   // 第一步：自底向上建堆


    SiftDown(arr, i, n);


 


  for (int len = n; len > 1; len--) {       // 第二步：反复取堆顶


    int t = arr[0]; arr[0] = arr[len - 1]; arr[len - 1] = t;


    SiftDown(arr, 0, len - 1);              // 堆长度减一后重新筛选


  }


}

📝 实验要点

  • 大根堆中任一结点值都 ≥ 其孩子结点值，故堆顶是当前堆中的最大元素
  • 建堆必须自底向上从最后一个非叶结点 n/2-1 开始下沉，才能保证每次调整时子树已是堆
  • 下标从 0 开始：结点 i 的孩子为 2i+1 与 2i+2，父结点为 (i-1)/2
  • 每取出一个堆顶，堆长度减一，只需对新的堆顶做一次下沉筛选，不必重新建堆
  • 已排序区间位于数组末尾并从右向左扩大，最终得到升序序列
  • 堆排序是不稳定排序，交换可能改变相等元素的相对次序
  • 时间 O(nlog₂n)、空间 O(1)，适合数据量较大且对辅助空间敏感的场景
